# Lumen Flexbox Landing

Адаптивный одностраничный сайт (лендинг), сверстанный с использованием методологии BEM, технологии Flexbox и медиа-запросов. Проект выполнен в рамках практических работ по верстке веб-интерфейсов.

## 📋 Описание проекта

Данный проект демонстрирует процесс превращения графического макета из Figma в полноценный адаптивный веб-сайт.

**Основные особенности:**
*   **Flexbox Layout:** Вся структура страницы построена на CSS Flexbox для гибкого управления расположением элементов.
*   **Desktop First:** Адаптивная верстка реализована по принципу "от большего к меньшему" (сначала десктоп, затем планшеты и мобильные устройства).
*   **CSS Variables:** Использование CSS-переменных для управления цветами и шрифтами, что упрощает поддержку темной/светлой темы.
*   **Dark Mode Support:** Автоматическое переключение цветовой схемы в зависимости от настроек операционной системы пользователя (`prefers-color-scheme`).
*   **Mobile Menu:** Реализация выпадающего бургер-меню для мобильных устройств с помощью JavaScript.
*   **Positioning:** Использование различных типов позиционирования (`relative`, `absolute`, `fixed`, `sticky`) для сложных элементов интерфейса.

## 🛠 Технологии

*   **HTML5** (Семантическая верстка)
*   **CSS3** (Flexbox, Media Queries, CSS Variables, Transitions)
*   **JavaScript** (Vanilla JS для работы мобильного меню)
*   **Figma** (Источник дизайн-макета)
*   **Google Fonts** (Шрифт Inter)
